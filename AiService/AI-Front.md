## 1. 页面目标

实现一个**可直接运行的前端页面**（优先单页 HTML/CSS/JS），效果类似 **AI 智能对话助手**，整体风格**精美、现代、简洁**，并满足以下功能与接口要求。

## 2. 页面布局与交互

### 2.1 整体布局

- 左侧：侧边栏（Sidebar）
  - 顶部：按钮 **「新建聊天」**
  - 下方：显示会话列表（Session List），每项包含会话标题（如“会话 #123456”）和删除按钮
- 右侧：主聊天区
  - 中间：消息对话列表（Message List），以气泡形式展示
    - AI 消息靠左，用户消息靠右
  - 底部：输入框（`<textarea>`） + **发送按钮**
  - 支持：
    - `Enter` 发送消息
    - `Shift + Enter` 换行

## 3. 会话管理

- 新建聊天：

  - 点击「新建聊天」按钮 → 创建一个新会话
  - 自动生成唯一的 **6 位整数 `sessionId`**（范围：100000 ~ 999999）
  
- 会话列表：

  - 每个会话项显示 `sessionId` 并提供 **删除按钮（×）**

- 删除逻辑：

  - 删除会话后，从列表中移除

  - 若删除的是

    当前激活会话：

    - 自动切换到其他任意一个会话（若存在）
  - 若无其他会话，则**自动新建一个会话**
    
- 若当前会话正在进行
  
    流式输出，删除时必须：

    - 调用 `AbortController.abort()` 中断请求
- 清理相关状态

## 4. 主题切换

- 提供一个 **主题切换按钮**（例如 ☀️ / 🌙 图标）

- 支持两种主题：

  - **白天主题（Light Mode）**
  - **黑夜主题（Dark Mode）**

- 切换时需同步更新：

  - 背景色、面板色、文字颜色、输入框样式等
  - 整体配色协调、柔和

- 持久化：

  - 用户选择的主题需保存至 `localStorage`
- 页面刷新后仍保持上次选择

## 5. 配色与视觉风格

- **禁止使用紫色系**作为主色调

- 推荐使用

  清淡、柔和

  的配色方案，例如：

  - 淡蓝、青灰、浅灰、米白等

- 整体 UI 需体现**高级感、轻量感、现代感**

## 7. 后端接口调用

### 7.1 请求地址

```http
POST http://localhost:10010/api/chat
```

### 7.2 请求体（JSON）

```json
{
  "sessionId": 123456,
  "userId": 789012,
  "prompt": "今天杭州的天气怎么样呢？"
}
```

### 7.3 参数生成规则

| 字段        | 生成规则                                                     |
| ----------- | ------------------------------------------------------------ |
| `sessionId` | 每个会话固定分配一个 **6 位随机整数**（100000 ~ 999999）     |
| `userId`    | 页面初始化时生成一次 **6 位随机整数**（100000 ~ 999999）<br>→ **写入 `localStorage`，刷新后不变** |
| `prompt`    | 用户在输入框中输入的文本内容                                 |

> 💡 说明：`userId` 在本次会话周期内固定，跨页面刷新保持一致，便于后端识别用户身份。

## 8. 流式输出（Streaming）

- 前端必须支持**流式响应处理**

- 实现要求：

  1. 用户点击发送后，**立即在消息区添加一条 AI 占位消息**（内容为空或“思考中…”）

  2. 使用 `fetch` + `ReadableStream` 读取响应流

  3. 实时将接收到的文本 **追加到该 AI 消息中**，并更新 DOM

  4. 兼容两种返回格式：

     - **普通 chunked `text/plain`**：直接拼接
   - **SSE 格式**（如 `data: hello\n\n`）：提取 `data:` 后的内容，忽略事件类型和注释
     
  5. 使用：

     ```
   AbortController
     ```
  
     - 在切换会话、删除会话或新建会话时，**中断当前流式请求**
- 防止旧响应污染新会话

## 9. 运行方式与兼容性

- **必须可直接运行**，无需复杂构建步骤

- 推荐方案：

  - 单文件 `index.html`（内联 CSS + JS）
  - 或提供完整可运行项目（如含 `package.json` 的 Vue/React 项目）
  
- 启动说明

  （如适用）：

  - 使用 VS Code Live Server
  - 或运行 `python -m http.server 8080`

- 尽量减少外部依赖

  （不强制使用框架）

  - 若使用框架（如 Vue/React），必须提供：
    - 完整项目结构
    - 清晰的启动命令（如 `npm install && npm run dev`）
